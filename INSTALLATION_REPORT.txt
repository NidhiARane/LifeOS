===============================================================================
                          TROUBLESHOOTING
===============================================================================

Problem: "venv is not recognized"
Solution: Make sure you're in the correct directory:
   cd "E:\WebBasedProjects\Life OS - BCA Project\LifeOS"

Problem: "Port 5000 already in use"
Solution: Kill the process:
   taskkill /F /IM python.exe

Problem: "Module not found" or "ImportError"
Solution: Make sure virtual environment is activated:
   .\venv\Scripts\Activate.ps1
   You should see (venv) prefix in command line

Problem: "Template not found"
Solution: Make sure you're running from the project root directory:
   cd "E:\WebBasedProjects\Life OS - BCA Project\LifeOS"

Problem: "Database locked"
Solution: Restart the app or delete lifeos_dev.db and restart

Problem: "Connection refused"
Solution: Make sure the Flask server is running on port 5000
