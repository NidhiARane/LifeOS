## ❓ QUICK TROUBLESHOOTING

**App won't start?**
- Check terminal for errors
- Make sure port 5000 is free

**Can't see Module 2?**
- Refresh page (F5)
- Make sure you're logged in
- Try direct URL: `/finance/dashboard`

**Data not showing?**
- Add some expenses/items first
- Charts only show with data

**Database error?**
- Delete `lifeos_dev.db`
- Restart app (it will recreate)
