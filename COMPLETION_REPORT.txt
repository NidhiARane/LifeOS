🚀 HOW TO RUN

Local Development:
  1. cd "E:\WebBasedProjects\Life OS - BCA Project\LifeOS"
  2. python -m venv venv
  3. venv\Scripts\activate
  4. pip install -r requirements.txt
  5. Create database: CREATE DATABASE lifeos_dev;
  6. python run.py
  7. Open: http://localhost:5000

  1. cd "E:\WebBasedProjects\Life OS - BCA Project\LifeOS"
  2. docker-compose up --build
