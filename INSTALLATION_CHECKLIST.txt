TROUBLESHOOTING QUICK FIX
═══════════════════════════════════════════════════════════════════════════

Problem: "venv command not found"
→ Make sure you're in the correct directory:
  cd "E:\WebBasedProjects\Life OS - BCA Project\LifeOS"

Problem: "Port 5000 already in use"
→ Kill the process:
  taskkill /F /IM python.exe

Problem: "Module not found" or "Import error"
→ Activate the virtual environment:
  .\venv\Scripts\Activate.ps1

Problem: "Template not found"
→ Make sure you're in project root directory:
  cd "E:\WebBasedProjects\Life OS - BCA Project\LifeOS"

Problem: "Database locked"
→ Delete lifeos_dev.db and restart the app

Problem: "Connection refused"
→ Make sure Flask is running on http://localhost:5000
