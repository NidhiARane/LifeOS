# Module 3: Quick Access Guide

## 🚀 Quick Navigation

### Meals Dashboard
- **URL**: `/health/meals`
- **Purpose**: View meal history and daily nutrition stats
- **Access**: Dashboard → Nutrition & Habits → Log Meals & Nutrition

### Log Meal
- **URL**: `/health/meal/log`
- **Form Fields**: Meal Name, Type, Date, Calories, Protein, Carbs, Fat
- **Time Taken**: < 1 minute per meal

### Habits Dashboard
- **URL**: `/health/habits`
- **Purpose**: Track daily habits and streaks
- **Access**: Dashboard → Nutrition & Habits → Track Habits

### Create Habit
- **URL**: `/health/habit/create`
- **Categories**: Health, Productivity, Learning, Wellness, Social, Finance
- **Frequency Options**: Daily, Weekly, Custom

### Goals Dashboard
- **URL**: `/health/goals`
- **Purpose**: Set and track personal goals
- **Access**: Dashboard → Nutrition & Habits → Manage Goals

### Create Goal
- **URL**: `/health/goal/create`
- **Categories**: Health, Financial, Learning, Fitness, Career, Social, Personal
- **Priority Levels**: Low, Medium, High

## 📊 Daily Routine Suggestion

### Morning

## 🥗 Nutrition Guidelines

### Daily Calorie Goal
- Sedentary: 1,800 - 2,200 kcal
- Moderate Activity: 2,200 - 2,800 kcal
- High Activity: 2,800 - 3,500+ kcal

### Daily Protein Goal
- General: 50-60g (0.8g per kg body weight)
- Strength Training: 1.2-2g per kg body weight
- Elderly: 1-1.2g per kg body weight

### Macronutrient Balance
- Protein: 20-35% of calories
- Carbs: 45-65% of calories
- Fat: 20-35% of calories

## 🐛 Troubleshooting

### Meal Not Saving?
- Check all required fields are filled
- Verify date/time format
- Ensure calories > 0

### Habit Check-in Failed?
- Already checked in today? Wait for tomorrow
- Try refreshing page
- Check browser console for errors

### Goal Not Updating?
- Verify current_value is a number
- Check target_value > 0
- Wait for modal to close after save

## 🎓 Best Practices

### Meal Logging
✅ Log immediately after eating
✅ Be specific with portion sizes
✅ Use nutrition labels when available
✅ Review weekly patterns

### Habit Tracking
✅ Keep habits small and specific
✅ Check in daily for best results
✅ Celebrate streaks
✅ Don't stress over missed days (streak resets)

### Goal Setting
✅ Use SMART criteria
✅ Break large goals into smaller steps
✅ Review progress weekly
✅ Adjust if unrealistic
